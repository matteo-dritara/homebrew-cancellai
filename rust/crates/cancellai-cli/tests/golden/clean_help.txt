Clean old session data - the only mutating command

Usage: cancellai-cli clean [OPTIONS]

Options:
      --days <DAYS>                Retention cutoff in days [default: 7]
      --keep-latest <KEEP_LATEST>  Always protect the N most-recently-modified sessions per tool, independent of age [default: 2]
      --tool <TOOL>                Restrict to one provider [default: all] [possible values: all, codex, claude]
      --json                       Machine-readable output
      --allow-running              Proceed even though a Codex/Claude process appears to be running, or liveness could not be determined
      --dry-run                    Preview only; never mutates
  -y, --yes                        Skip interactive confirmation
      --keep-claude-history        Leave Claude's history.jsonl untouched. Accepted for the reference CLI's scripts: this engine never rewrites history.jsonl, with or without the flag
      --verbose                    Report every performed action, not only the totals; never changes which actions run
  -h, --help                       Print help
